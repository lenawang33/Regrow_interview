# REGROW
This Repository displays my ability to code and analyze spatial water and soils data using python. 

# Table of Contents
(1) First3_Last3_GWMA.csv - Groundwater Well Nitrate Data. First and last 3 years of the monitoring period for 36 wells across the Southern Willamette Valley Groundwater Management Area. 

(2) GWAMA_nitrate_data_Wang_20250204.csv - All Groundwater Well Nitrate Data.

(3) Groundwater_Management_Area_So_Willamette_Valley.geojson - Spatial file showing outline of the Southern Willamette Valley Groundwater Management Area as a .geojson. 

(4) Groundwater_Management_Area_So_Willamette_Valley.zip - Added spatial file showing outline of the Southern Willamette Valley Groundwater Management Area as a .shapefile.

(5) Kansas_Duplicates.csv - Soil Health Data from Kansas Samples, fully public on EPA's Sciencehub.

(6) Oregon_State_Boundary_4303926865431890091.geojson - Shape of the State of Oregon as a .geojson. 

(7) Regrow_Interview.py - Coding Sample

(8) Soil1_20231127_LW QAQC.xlsx - Soil Health Data from Oregon Samples, fully public and associated with Weitzman et al., (2024) paper. Weitzman, J.N., Brooks, J.R., Compton, J.E., Faulkner, B.R., Peachey, R.E., Rugh, W.D., Coulombe, R.A., Hatteberg, B. and Hutchins, S.R., 2024. Vadose zone flushing of fertilizer tracked by isotopes of water and nitrate. Vadose Zone Journal, 23(3), p.e20324.
